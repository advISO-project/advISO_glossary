# advISO_glossary

This repository contains the source files for the `advISO Glossary of Terms<https://adviso-glossary.readthedocs.io/en/latest/>`__/. A shared glossary of ISO 15189 terms, each with a definition, a bioinformatics translation, example usage and ontology references. It gives wet lab and bioinformatics staff a common language, and anyone can propose new terms or changes via the `GitHub issues<https://github.com/advISO-project/advISO_glossary/issues/new/choose>`_/ page.
